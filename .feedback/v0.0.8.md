# Rift feedback — v0.0.8 campaign

Observations from using Rift MCP while fixing current-tree index coherence.

## Observations

- The first project `search` blocked for about 160 seconds while Rift built the index, then returned
  an empty result with complete coverage and `freshness: "current"`. Startup work needs visible
  task state; a request that produces no output for that long looks hung.
- v0.0.7 exposed the correctness failure: external edits did not rebuild the long-lived snapshot,
  while reads still reported current freshness. An empty result therefore claimed absence from an
  older tree.
- v0.0.8 starts a native watcher before the initial scan, reconciles an exact workspace fingerprint
  at request time, and publishes each complete index/configuration snapshot atomically. External
  writes and Rift changes use the same rebuild lane.
- MCP stdio reserves stdout for protocol frames. Tracing output belongs on stderr; writing logs to
  stdout corrupts the transport.
