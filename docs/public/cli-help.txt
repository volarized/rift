$ rift --help
agentic development toolkit

Usage: rift [COMMAND]

Commands:
  config   Set this project's or the user's configuration
  mcp      Serve agents over stdio MCP by proxying this workspace's rift server
  server   Manage this workspace's HTTP MCP server
  update   Replace current Rift binary with latest official release
  install  Generate or remove a coding agent's Rift skill
  steer    Answer one Claude Code `PreToolUse` hook call from stdin
  help     Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version

$ rift config set --help
Set request statistics or a language server in this project's rift.toml

Usage: rift config set [OPTIONS]

Options:
      --telemetry.disabled=<BOOL>    Disable request statistics with true, or enable them with false [possible values: true, false]
      --language <LANGUAGE>          Exact language identity, such as typescript or typescript:tsx
      --profile <PROFILE>            Named local project registered in mcp.extra; absence selects the primary project
      --profile-root <PROFILE_ROOT>  Workspace-relative folder for a new named local project
      --include <INCLUDE>            Language path pattern within the selected project, repeated for additional patterns
      --exclude <EXCLUDE>            Language path pattern to exclude within the selected project
      --lsp-program <LSP_PROGRAM>    Executable name or relative path, started directly without a shell
      --lsp-argument=<LSP_ARGUMENT>  Literal process argument, repeated for additional arguments
      --user                         Write ~/.rift/config.toml; a user disable applies to every project
  -h, --help                         Print help

$ rift server --help
Manage this workspace's HTTP MCP server

Usage: rift server <COMMAND>

Commands:
  start    Start this workspace's server, detached unless --foreground
  stop     Stop this workspace's server
  restart  Stop this workspace's server, then start a fresh detached one
  status   Report whether this workspace's server is serving
  logs     Print this workspace's recorded server diagnostics, oldest first
  help     Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help

$ rift server logs --help
Print this workspace's recorded server diagnostics, oldest first

Usage: rift server logs [OPTIONS]

Options:
  -f, --follow            Keep printing records as the server writes them
  -n, --tail <COUNT>      Print only the newest COUNT records; `all` prints every kept record [default: all]
      --since <WHEN>      Print only records recorded at or after WHEN: an age such as `10m` or `2h`, or an RFC 3339 timestamp such as `2026-10-04T20:42:58Z`
      --until <WHEN>      Print only records recorded before WHEN, in the forms `--since` takes
      --level <LEVEL>     Print only records at this severity, as the store spells it [possible values: trace, debug, info, warn, error]
      --component <NAME>  Print only records one component emitted, as its spans label it: index, search, engine, change, or logs
  -h, --help              Print help
