# SVGL components

Source: [SVGL shadcn registry](https://svgl.app/docs/shadcn-ui).

`huggingFace.tsx` comes from `@svgl/hugging-face`; `openai.tsx` comes from `@svgl/openai`.
Downloaded 2026-09-19, formatted with the docs formatter, and given the SVG title required by docs
linting.

Language logos come from `@svgl/html5`, `@svgl/css`, `@svgl/angular`, `@svgl/vue`,
`@svgl/svelte` and `@svgl/markdown`. Downloaded 2026-10-10 from the registry,
formatted with the docs formatter, and given SVG titles. `components.json` includes the
`@svgl` registry for later additions.

`json.tsx` uses the [JSON logo](https://upload.wikimedia.org/wikipedia/commons/c/c9/JSON_vector_logo.svg)
supplied by the author. Each instance has unique gradient IDs because JSON and JSONC appear
together with other SVG logos on the same page.

`toml.tsx` uses the [TOML logo](https://upload.wikimedia.org/wikipedia/commons/c/c1/TOML_Logo.svg)
supplied by the author.
