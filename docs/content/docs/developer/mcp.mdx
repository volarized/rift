Select a tool or resource to inspect its parameters and example results. This demo uses stored
payloads and sends no requests.

Tool descriptions, schemas, and JSON examples come from the exported [MCP schema](/mcp.json).
`rift mcp --output=all` returns both `content` and `structuredContent`; the demo shows both
representations. Resource reads return `contents` with each entry's MIME type.
