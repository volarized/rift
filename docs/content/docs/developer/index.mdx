title: Developer
---

Rift runs one local server per workspace and shares its index between MCP clients. These pages
explain the server's implementation; [installation](/docs/installation) and
[agentic usage](/docs/agentic-usage) cover running it with an agent.

- [Architecture](/docs/developer/architecture) explains which processes run and how providers
  supply code facts.
- [Implementation](/docs/developer/implementation) describes index construction and storage.
- [Configuration](/docs/developer/configuration) defines workspace settings in `rift.toml`.
- [Testing](/docs/developer/testing) covers local checks and CI.
- [Protocol](/docs/developer/protocol) describes the models behind the
  [MCP surface](/docs/mcp).
