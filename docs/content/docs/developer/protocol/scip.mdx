<VersionBadge version="planned" />

Rift plans to export provider facts as a [SCIP](https://github.com/sourcegraph/scip) index for
consumers that read that format. The export covers documents and symbol occurrences, together
with the relationships and documentation providers resolved.

The current [MCP surface](/docs/mcp) serves code reads. This planned export has no served endpoint.
