An agent calls three tools and reads four resources. `search`, `match` and `actions` take parameters
and return a result; the repository, symbol, diff and file resources are read by URI.

Everything answers against the default branch unless you pass a `rev`. Every response reports the
snapshot it resolved to, so when two calls have to agree you pass that back rather than naming the
branch twice and hoping it did not move.

An answer too large for one response ends with a **cursor**: an opaque string naming the request, the
state and the page size it was produced under. Send it back for the next page. If the workspace has
moved past that state the cursor is refused, because the alternative is a second page answered against
code the first page never saw.

When something cannot be done you get a typed failure: a stable code, whether retrying can help, and
the evidence behind it.
