An agent calls Rift through tools and resources. A tool accepts parameters and returns a result. A
resource URI identifies data the agent can read, such as `rift://file/pkg/util.py`.

A request uses the latest commit on the default branch when `rev` is absent. The response reports the
resolved state as a `Snapshot`. Reuse that snapshot when later calls must read the same state.

An answer too large for one response includes an opaque continuation string called a `Cursor`. It is
bound to the original request and snapshot. Send it back to read the next page. Rift refuses it after
the workspace moves because every page must use the same source state.

A failed request returns a stable error code. Its retry directive says whether another attempt can
succeed, and the remaining fields carry the evidence for the failure.
