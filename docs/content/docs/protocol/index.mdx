MCP connects an agent to `rift mcp`. The adapter protocol connects the workspace server to language
adapters. SCIP export serves tools that consume SCIP indexes.

These boundaries share the [core model](/docs/protocol/core). The generated
[reference](/docs/protocol/reference) is authoritative for fields, enums, and wire numbers.

## Session flow

1. `rift mcp` starts or connects to the server for a workspace.
2. `Connect` opens a session and returns its current projection state.
3. Reads and changes use that projection.
4. Changes name the head they observed.
5. `publish` applies non-conflicting projection changes to the workspace.

Rift FS exposes the projection to adapters and filesystem tools when they need a path.

## Compatibility

Generated contracts carry a major version, minor version, and schema digest. Peers communicate when
one descriptor matches exactly. Unknown fields are rejected.
