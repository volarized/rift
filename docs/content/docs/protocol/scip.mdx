---
title: SCIP
---

SCIP export streams semantic facts from one session view as a `scip.Index`.

## Request

`Read` receives a `ProjectionHead`. The server reads the corresponding adapter state and emits
events in canonical SCIP order:

1. one header;
2. documents in project-path byte order;
3. external symbols in encoded-symbol order.

The header repeats the head, carries SCIP metadata, and reports semantic coverage.

## Mapping

Rift maps source documents, occurrences, symbols, relationships, signatures, and documentation to
their SCIP equivalents. Paths remain workspace-relative. Source ranges use SCIP line and character
coordinates after conversion from Rift's UTF-8 byte ranges.

`Omission` records a populated Rift field that the pinned SCIP schema cannot express. Each entry
names the field, reason, count, and affected language. This keeps a successful export explicit about
lost facts.

The stream is read-only and uses the same adapter-derived state as MCP semantic reads.
