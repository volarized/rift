---
title: Configuration
---

Rift reads `rift.toml` from the workspace root. The generated
[`rift.schema.json`](/rift/protocol/rift.schema.json) defines the file and rejects unknown keys.
Changes apply to later requests after validation succeeds.

```toml
#:schema ./protocol/rift.schema.json

[execution]
allow = []
debug = []

[validation]
require = "available"

[validators]
commands = []
```

## Adapters

Each entry below `adapters` names one process. `command` is an executable followed by literal
arguments. `env` adds environment values.

```toml
[adapters.rust]
command = ["rift-adapter-rust"]
env = { RUST_LOG = "warn" }
```

After launch, the process describes its language and capabilities through the adapter protocol.

## Execution

`execution.allow` lists languages permitted to evaluate caller code. `execution.debug` selects a
subset permitted to retain post-mortem frames. A selector is a language name or `name:dialect`.

The remaining fields bound code size, duration, captured output, concurrency, retained debug
sessions, frames, bindings, and rendered values. Durations use units such as `ms`, `s`, and `m`;
byte sizes use `B`, `KiB`, and `MiB`.

## Validation

`validation.require = "available"` requires complete reports from affected adapters that advertise
validation. A list of language selectors requires reports for those languages.

`validators.commands` adds workspace commands to the validation pass. Rift starts each command
directly in a disposable copy of the projection. A declaration sets its argument vector, working
directory, environment, timeout, output limit, changed-path behavior, and guarantees.

```toml
[[validators.commands]]
id = "tests"
kind = "test"
argv = ["cargo", "test"]
changed_paths = "none"
working_directory = ""
environment = {}
timeout_ms = 120000
output_limit_bytes = 4096
guarantees = []
determinism = "deterministic"
```
