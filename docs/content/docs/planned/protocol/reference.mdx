The planned reference is generated, not authored: every type on these pages is defined by the
Rust wire models in `crates/rift-protocol/src`, and the schema document the server exports is
what a reference page renders. The shipped surface's export lives at
[`docs/protocol/mcp.json`](https://github.com/volarized/rift/blob/main/docs/protocol/mcp.json).

Until the planned surface ships, type links from these pages name definitions in that export
where they exist, and the design prose on the [core](/docs/planned/protocol/core) and
[MCP](/docs/planned/protocol/mcp) pages where they do not.
