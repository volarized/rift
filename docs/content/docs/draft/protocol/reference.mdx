The reference follows the axis groups declared in the generated MCP schema. Within each group, a type
appears under the first definition that refers to it. Related shapes therefore stay on the same
branch.

SCIP-owned types live with the [SCIP projection](/docs/draft/protocol/scip). Links from shared types resolve
to that page.
