---
title: Installation
description: Install rift and configure your agent to use it in your project.
---

Rift runs on your machine alongside your agents. To use it in a project, install the executable
and configure your agent to launch it from the folder containing your codebase.

## Install

Choose the command for your platform and run it in your terminal:

<PlatformTabs>

<Tab value="Linux and macOS">

```sh
curl --proto '=https' --tlsv1.2 -fsSL https://volar.sh/rift/install.sh | bash
```

</Tab>

<Tab value="Windows PowerShell">

```powershell
irm https://volar.sh/rift/install.ps1 | iex
```

</Tab>

</PlatformTabs>

The installer downloads the latest verified release for your platform and installs it for the
current user. To install a specific version, set the `RIFT_VERSION` environment variable to its
release tag.

If the installer asks you to add its installation directory to `PATH`, add that directory so your
terminal and agent can find `rift`.

## MCP configuration

Once rift is installed, your agent needs to know how to start it. In Claude Code, add the
following server entry to `.mcp.json` in your project root:

```json
{
  "mcpServers": {
    "rift": {
      "command": "rift",
      "args": ["mcp"]
    }
  }
}
```

The `command` names the installed executable, and `args` selects its MCP mode. Your agent launches
`rift mcp` from the project folder, so rift builds its local index from that project's codebase.

For another MCP client, configure it to launch the same command from your project folder.
If you're using Claude Code, [Agentic usage](/docs/agentic-usage) explains how to install the Rift
skill that teaches your agent which tool to call.

## Update

To update an existing installation, run:

```sh
rift update
```
