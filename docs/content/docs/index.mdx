title: Rift
---

Rift is an agentic development toolkit for discovering and editing code.

The mechanism pages and generated reference describe the current contract. The Rust binary currently
provides the CLI shell; the server and adapter runtime still have to implement that contract before a
client can rely on it.

An agent such as Claude Code or Codex starts `rift mcp` in a Git worktree. That process resolves the
canonical physical workspace path and forwards requests to that workspace's `rift server`. The server
uses Git refs and registered worktrees for durable sessions, while semantic facts stay in process
memory or a disposable cache. It calls language adapters admitted by user-owned policy. A linked Git
worktree at another physical path is a separate Rift workspace even when both paths share Git objects.

Most users only need the agent configuration that launches `rift mcp`. The remaining pages describe
the server and its protocol for adapter authors, client implementers, and people debugging a
workspace:

- [Architecture](/docs/architecture) follows a request through the MCP process, workspace server, Git
  worktrees, and language adapters.
- [Configuration](/docs/configuration) shows how committed project requests intersect with
  user-owned executable grants and limits.
- [Protocol](/docs/protocol) documents the MCP JSON surface, its gRPC mapping, the adapter service,
  and the read-only SCIP projection.
