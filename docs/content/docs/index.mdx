Rift gives an agent a writable projection of any directory. The agent reads and changes code through
MCP; language adapters provide semantic facts and refactors. When the work is ready, the agent
publishes its changes into the directory.

The [architecture](/docs/architecture) defines the system's target behavior. [Configuration](/docs/configuration)
controls workspace policy. The [protocol](/docs/protocol) specifies the boundaries used by MCP clients,
language adapters, and SCIP consumers.
