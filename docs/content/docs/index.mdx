---
title: Rift
---

Rift is an agentic development toolkit for reading, discovering and editing codebases. Your agent
gets a scratchpad copy of your project, works in it through MCP, and merges the result back when
you're happy with it.

Rift is per se not a complex system, and most of what follows matters if you're implementing
against the protocol or writing a language adapter. If you want to know how the server actually
works, take a tour:

- Architecture — the processes, what each of them owns, and how a change gets from your agent
  into your files
- Configuration — the `rift.toml` keys that shape behaviour, for the server and for language
  adapters
- Protocol — the MCP surface in detail, and how a request turns into an adapter call. There's a
  SCIP-compatible export here too.
